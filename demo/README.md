# Referee Demo

This is a standalone demo version of the referee features for testing purposes.

## How to Use

1. Open `referee_demo.html` in your web browser
   - Simply double-click the file or drag it into your browser
   - No server needed - it's a standalone HTML file

## Features to Test

### 1. **Shot Tracking**
- Click anywhere on the basketball court
- Select shot type (2-pointer or 3-pointer)
- Score updates automatically
- Visual markers show shot locations

### 2. **Foul Handling**
- Click "Foul (2FT)" or "Foul (3FT)" for either player
- Free throw modal appears automatically
- Track make/miss for each free throw
- Score updates when free throws are made

### 3. **Score Tracking**
- Live score display for both players
- Updates in real-time as events are recorded

### 4. **Event Log**
- All actions are logged with timestamps
- Scrollable history of all events

### 5. **Reset**
- Click "Reset Demo" to start fresh

## What This Demo Shows

This demo demonstrates the referee interface features that are implemented in the full app:
- Interactive court for shot tracking
- Foul handling with automatic free throw modal
- Real-time score updates
- Event logging

## Integration with Full App

In the full app, these features are integrated with:
- Database persistence
- Real user accounts
- 1v1 matches and team challenges
- Heat map visualization from recorded shots
- Player statistics tracking

## Notes

- This is a frontend-only demo (no backend)
- Data is not saved between sessions
- Use for testing UI/UX and feature demonstration
